# 🤖 AI Chatbot

An intelligent AI-powered chatbot built using Python, Streamlit, and the OpenAI API.

The application provides conversational AI responses with chat history, secure API-key handling, a clean user interface, and an easy-to-use student-friendly design.

---

## 🚀 Features

- 🤖 AI-powered conversational chatbot
- 💬 Real-time chat interface
- 🧠 Conversation memory
- 🗑️ Clear chat functionality
- 🔐 Secure API key management using `.env`
- 🎨 Clean Streamlit user interface
- ⚡ Fast AI responses
- 🧑‍💻 Programming assistance
- 📚 Student learning assistance
- ❌ Error handling
- 📱 Responsive web interface

---

## 🛠️ Technologies Used

- Python
- Streamlit
- OpenAI API
- python-dotenv
