# 🤖 AI Study Assistant

An AI-powered study assistant built with **Python, Streamlit, and the OpenAI API**.

It helps students understand topics, ask questions, summarize notes, and generate multiple-choice questions using AI.

---

## ✨ Features

### 💬 Ask AI

Ask questions about programming, technology, academics, or any other topic.

### 📖 Explain Topic

Enter a topic and select your learning level:

* Beginner
* Intermediate
* Advanced

The AI provides a structured explanation with examples and interview questions.

### 📝 Summarize Notes

Paste your study notes and get:

* Key points
* Important terms
* Quick revision notes
* Simple summary

### ❓ Generate MCQs

Enter a topic and generate up to 10 multiple-choice questions with:

* Question
* Four options
* Correct answer
* Explanation

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd ai-study-assistant
```

### 3. Install dependencies

```bash
pip3 install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

---

## 🔐 API Key

The application asks for an API key at runtime.

**Never upload your private API key to GitHub.**

Do not put your API key directly inside `app.py`.
